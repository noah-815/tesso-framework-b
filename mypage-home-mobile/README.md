# Tesso — My Page Home (Mobile)

Framework B `mypage/home` 의 모바일(뷰포트 ≤ 767) 구현.
Figma node `7093:90320` (주문 3건) · `7093:90245` (주문 없음).
데스크탑 버전은 [`../mypage-home-desktop/`](../mypage-home-desktop/) 에 있습니다.

**확인 목적:** 섹션 `content` 의 `min-height` 를 `mid-100` 으로 뒀을 때 뷰포트별로 적절한가.
하단 패널에서 주문 건수(0~3)와 min-height 안(mid-100 / 100px 시안값 / off)을 바꿔가며
비교할 수 있고, 읽기값에 **min-h 계산값 · 실제 콘텐츠 높이 · 적용 여부**가 표시됩니다.

```
index.html      # 마크업 + 전체 스타일
assets/         # Figma 익스포트 썸네일 3종 (320px 로 리사이즈)
```

디바이스 목업(상단 statusBar · 하단 브라우저 바)은 제외하고 서비스 화면만 구현했습니다.

## 측정 결과 — mid-100

`min-height` 로 막아야 할 대상인 **주문 1건의 높이는 101 → 120px 로 거의 고정**입니다
(썸네일 80px 이 px 고정이라). 반면 `mid-100` 은 83 → 189px 로 두 배 넘게 움직입니다.

굵게 표시된 것이 min 이 실제로 걸린 경우입니다.

| viewport | `mid-100` | 0건 | 1건 | 2건 | 3건 |
|---|---|---|---|---|---|
| 320 | 83.5px | 39.5 → **83.5** | 101.1 → 101.1 | 192.4 | 283.7 |
| 390 | 100px | 46.4 → **100** | 104.0 → 104.0 | 196.0 | 288.0 |
| 450 | 114.1px | 52.3 → **114.1** | 106.5 → **114.1** | 199.1 | 291.7 |
| 767 | 188.9px | 65.3 → **188.9** | 119.5 → **188.9** | 215.3 | 311.2 |

- **0건**은 전 구간에서 걸립니다.
- **1건**은 **410px 을 기점**으로 갈립니다. 그 아래(320·390)에서는 안 걸리고, 450 부터 걸립니다.
  기준 폭 390 에서 min-h 100px < 1건 104px 이라 **시안 기준 뷰포트에서 이미 무효**입니다.
- **2건 이상은 어느 뷰포트에서도 영향 없습니다** (192px 이상).
- 767 에서는 120 → 189px 로 **69px 빈 공간**이 생깁니다.

### 고정 100px 과 비교

| viewport | `mid-100` 0건 / 1건 | `100px` 0건 / 1건 |
|---|---|---|
| 320 | 83.5 / — | **100** / — |
| 390 | 100 / — | **100** / — |
| 450 | 114.1 / **114.1** | **100** / — |
| 767 | 188.9 / **188.9** | **100** / — |

둘 다 1건은 못 막습니다. 시안값 100px 은 1건 높이(101~120px)보다 애초에 작아서
**0건 전용**으로만 동작하고, 그 점에서는 뷰포트와 무관하게 일관됩니다.

### 데스크탑과 비교

| | 데스크탑 (mid-120) | 모바일 (mid-100) |
|---|---|---|
| 썸네일 | 72px | 80px |
| 1건 높이 | 96 ~ 101px | 101 ~ 120px |
| min-h 범위 | 83 ~ 157px | 83 ~ 189px |
| 1건 커버 기점 | 1440px (실사용 구간 포함) | 410px (390 에서 이미 무효) |

모바일은 썸네일이 더 큰데(80px) 토큰은 더 작아서(mid-100), 1건 커버가 데스크탑보다
더 안 됩니다. **1건까지 덮으려면 최소 120px 이상**이 필요합니다
(767 기준 1건 119.5px). `mid-*` 로 가려면 mid-120 이상, 고정으로 가려면 120px 입니다.

## 단위 체계

디자인 기준 폭 **390** (시안 프레임 393).

```css
--tw: min(100vw, 450px);      /* 타이포 기준 폭 — 450px 이후 고정 */
--ut: calc(var(--tw) / 390);  /* 타이포 1px */
--us: calc(100vw / 390);      /* spacing 1px */
```

### 1. 타이포그래피 — 전부 가변

| 토큰 | 쓰임 | @320 | @390 | @450 이상 |
|---|---|---|---|---|
| `caption-2` 12px | 주문일 | 9.85px | 12px | 13.85px |
| `paragraph-4` 13px | 탭 · 상품명 · 가격 · 라벨 | 10.67px | 13px | 15px |
| `paragraph-3` 14px | 섹션 타이틀 · 설명 · 값 | 11.48px | 14px | 16.15px |
| `paragraph-1` 18px | 페이지 타이틀 · 인사말 | 14.77px | 18px | 20.77px |

BRAND 로고(20px)만 가변 로직 제외 → px 고정.

### 2. spacing

```css
--mid-4: 4px; --mid-6: 6px; --mid-8: 8px;      /* 값 ≤ 8 → 고정 */
--mid-12:  calc( 4 * var(--us) + 8px);
--mid-16:  calc( 8 * var(--us) + 8px);
--mid-20:  calc(12 * var(--us) + 8px);
--mid-24:  calc(16 * var(--us) + 8px);
--mid-32:  calc(24 * var(--us) + 8px);
--mid-40:  calc(32 * var(--us) + 8px);
--mid-100: calc(92 * var(--us) + 8px);
--px-16:   16px;                               /* 좌우 여백 — 고정 */
```

| 영역 | 값 |
|---|---|
| titleArea | padding `mid-20 / px-16 / mid-16` |
| tabs | 좌우 padding `mid-4`, 탭 항목 상하 `mid-16` · 좌우 12px |
| content | 좌우 `px-16`, 하단 `mid-40` |
| greeting | 상하 padding `mid-32`, gap `mid-8` |
| section | 상하 padding `mid-32` |
| sectionHead | gap `mid-24`, 하단 padding `mid-16` |
| sectionBody | **min-height `mid-100`** (검증 대상), 상단 padding `mid-24` |
| order | gap `mid-16` · 내부 `mid-8` / `mid-6` / `mid-4` |
| profile 블록 gap | `mid-24` · 내부 `mid-12` / `mid-8` |

좌우 여백이 `px-16`(고정)이라 데스크탑과 달리 뷰포트가 커져도 여백은 그대로입니다.

### 3. 그 외 px

header 60px, 썸네일 80px, 탭 좌우 padding 12px, divider 1×12px, hairline 1px,
`전체보기`·`프로필 관리` 밑줄 버튼 padding 1/2px.

### 4. 폰트

```css
--font: "Work Sans", "Pretendard Variable", Pretendard, sans-serif;
```

## 검증

390 기준 시안값과 일치: titleArea 63px, tabs 54px, 주문 3건 content 288px, header 60px.
320 · 450 · 767 에서 가로 스크롤 없음, 콘솔 에러 없음.

## 참고

- **탭 줄** — 6개 항목이 390 에서 딱 맞고 320 에서는 넘칩니다. `overflow-x: auto` 로
  가로 스크롤되게 했습니다 (스크롤바는 숨김). 시안에는 없는 처리입니다.
- 하단 데모 패널은 시안에 없는 요소입니다. `.demo-nav` / `.demo-seg` / `.demo-readout`
  CSS 와 `#demoNav` 마크업, 그 아래 스크립트를 지우면 됩니다.
- 프로필 섹션의 `content` 도 같은 `min-height` 를 씁니다. 내용이 항상 250px 을 넘어
  실질적으로는 영향이 없습니다.
